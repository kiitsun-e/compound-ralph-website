View learnings that have been automatically captured during implementation. Learnings are stored in `.borg/learnings.json` and accumulate across iterations.

## Usage

```bash
borg learnings [category] [limit]
```

## Arguments

| Argument | Required | Default | Description |
|----------|----------|---------|-------------|
| `category` | No | (all) | Filter by category type |
| `limit` | No | 20 | Maximum entries to display |

## Categories

Learnings are automatically categorized by type:

| Category | Description |
|----------|-------------|
| `environment` | Setup and configuration discoveries |
| `pattern` | Code patterns found in the codebase |
| `gotcha` | Unexpected behaviors or edge cases |
| `fix` | Successful error resolutions |
| `discovery` | General findings during exploration |
| `iteration_failure` | Issues that caused iteration problems |

## How Learnings Are Captured

During `borg implement`, learnings are recorded automatically when:

- The agent discovers existing code patterns
- Tests fail and are subsequently fixed
- Environment issues are resolved
- Unexpected behaviors are encountered

Each learning includes:
- **Date**: When it was recorded
- **Spec**: Which feature spec it relates to
- **Iteration**: The iteration number
- **Category**: Type of learning
- **Learning**: The actual insight
- **Files**: Related files (if applicable)

## Storage

Learnings are stored in `.borg/learnings.json`:

```json
{
  "learnings": [
    {
      "date": "2026-01-21T14:30:22-05:00",
      "spec": "user-authentication",
      "iteration": 3,
      "category": "pattern",
      "learning": "Use existing auth utility in src/lib/auth.ts",
      "files": ["src/lib/auth.ts"]
    }
  ]
}
```

## Examples

### View all learnings

```bash
borg learnings
```

### Filter by category

```bash
borg learnings fix
# Shows only successful error fixes

borg learnings pattern
# Shows only discovered code patterns
```

### Limit results

```bash
borg learnings "" 5
# Shows last 5 learnings (all categories)

borg learnings gotcha 10
# Shows last 10 gotchas
```

## Why Learnings Matter

Learnings compound across iterations:

1. **Fresh Context Each Iteration**: Claude starts fresh each time
2. **Learnings Persist**: Stored in `.borg/learnings.json`
3. **Context Injection**: Recent learnings are included in the prompt
4. **Avoid Repeated Mistakes**: The agent sees what worked before

This enables the loop to get smarter over time without requiring manual intervention.
